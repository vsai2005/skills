# Telemetry Gateway Update

In today's fast-paced software landscape, it is important to note that Telemetry Gateway v4.2 delivers a robust and seamless performance improvement for our users. Furthermore, testing in EU-West-1 demonstrated a significant enhancement, with median ingest latency being reduced by 17%. Additionally, the retry budget remains unchanged, which is an important consideration for operational consistency. Moreover, there are no schema changes associated with this update, and the request cap continues to remain at 500 requests per minute. In conclusion, the rollout is scheduled for October 14. Overall, this update represents a powerful step forward while maintaining the reliability and compatibility that users expect from the Telemetry Gateway platform.
