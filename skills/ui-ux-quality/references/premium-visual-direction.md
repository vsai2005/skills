# Premium Visual Direction

Use this reference when the user explicitly wants a distinctive, premium, expressive, cinematic, memorable, or non-template visual experience.

The objective is not "add effects." The objective is a coherent art direction that is specific to the product.

## 1. Diagnose generic generated-looking UI correctly

Do not call a UI "AI-generated" because it contains one trendy pattern.

The stronger warning signs are:

- the structure could serve almost any company;
- the copy, imagery, data, and interactions are interchangeable;
- every idea is forced into the same card pattern;
- decoration is doing more work than hierarchy;
- the interface contains generic fake metrics or placeholder content;
- different screens do not share a stable visual/interaction system;
- important loading, error, empty, disabled, mobile, or edge states are unresolved;
- the output looks like a first-pass template that was never challenged.

Common recurring clichés can be useful clues when several appear together:

- generic centered hero + two buttons;
- repeated three-column feature grid;
- purple/blue gradient without brand reason;
- glassmorphism everywhere;
- identical rounded cards and shadows everywhere;
- glowing borders and decorative blobs without product meaning;
- the same fade-up-on-scroll animation on every section;
- random 3D object in the hero that communicates nothing.

Do not ban these patterns universally. A deliberate gradient, card grid, glass surface, or centered hero can be excellent.

## 2. Write a visual-direction contract before styling

For a substantial expressive redesign, define:

- **product personality** — precise, playful, editorial, technical, luxurious, energetic, calm, etc.;
- **visual motif** — the one recurring idea that makes the product recognizable;
- **content hierarchy** — what should dominate and what should stay quiet;
- **type character** — restrained utility, editorial contrast, technical mono accents, etc.;
- **surface/depth model** — flat, layered, material, photographic, spatial;
- **image/illustration/3D role** — explain, demonstrate, brand, or decorate;
- **motion character** — snappy, physical, cinematic, restrained, elastic;
- **signature moments** — one or two memorable interactions, not effects everywhere;
- **restraint rules** — where the UI must remain calm for reading or task completion.

Prefer one coherent memorable idea over many unrelated "cool" effects.

## 3. Use product-specific composition

Do not let a component library decide the entire page structure.

Look for opportunities to create a composition that follows the content:

- one large focal object plus supporting detail instead of equal cards;
- editorial asymmetry when it improves hierarchy;
- data or product preview that reflects a real task;
- meaningful contrast between dense and quiet sections;
- a layout break at a narrative turning point;
- product-specific diagrams, illustrations, photography, or 3D assets;
- real trust signals and evidence instead of decorative testimonials.

Use reusable components underneath, but do not make every section visually interchangeable.

## 4. Typography should carry identity

Avoid reaching automatically for the same default sans stack only because it is safe.

Inspect the existing brand first. When typography changes are justified:

- choose type roles, not random fonts;
- create clear display/body/supporting contrast;
- protect reading measure and legibility;
- avoid excessive font-family count;
- use weight, width, tracking, case, and scale intentionally;
- test real content, long labels, numbers, and localization.

A distinctive type system can do more for originality than extra gradients or effects.

## 5. Use a novelty budget

A premium interface needs memorable moments, but not every element should compete for attention.

A useful default:

- **1 primary signature moment** — hero/product reveal, spatial demo, or major narrative transition;
- **1–3 supporting motion/visual motifs** — reused coherently;
- **quiet utility UI** — forms, settings, data entry, and routine controls stay predictable.

If everything is special, nothing is special.

## 6. Separate inspiration from imitation

When external references are used:

1. identify the underlying principle;
2. map it to the current product;
3. change composition, content, and visual language to fit the product;
4. do not copy another site's branded composition or signature interaction wholesale.

The goal is reference-driven judgment, not cloning.

## 7. Use authentic assets

Prefer product-specific assets when available:

- real product screenshots/data;
- original or licensed photography;
- meaningful illustration;
- product diagrams;
- actual 3D models;
- brand iconography.

Do not fabricate metrics, customer logos, testimonials, awards, screenshots, or product capabilities merely to make a page look premium.

## 8. Review originality with practical tests

### Substitution test

If changing only the logo, company name, and accent color would make the same page plausible for many unrelated products, the visual concept is probably too generic.

### Repetition test

If most sections can be described as "heading + paragraph + rounded cards", introduce hierarchy or composition variation where the content supports it.

### Purpose test

For each strong visual effect, ask:

> What product idea, action, state, or story does this effect clarify?

If the answer is only "it looks cool", keep it only when the brief is intentionally artistic and it does not harm the task.

### Screenshot vs product test

A premium screenshot is not enough. Inspect navigation, states, responsive layouts, real content, and interactions before calling the product refined.

## 9. Avoid reverse slop

"Anti-AI" can become its own cliché.

Do not mechanically add:

- wild asymmetry;
- oversized type;
- custom cursors;
- grain/noise;
- brutalism;
- 3D;
- scroll hijacking;
- excessive editorial layouts;

just to prove the interface is different.

Originality comes from specific decisions that fit the product, not from maximizing novelty.
